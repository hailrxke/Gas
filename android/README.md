# GAS для Android

Отдельный нативный клиент на Kotlin и Jetpack Compose для существующего Python API из `../server`. Минимальная версия — **Android 8.0 / API 26**, compile/target SDK — 35, JDK — 17. Английский интерфейс повторяет структуру iOS-клиента: оранжевые акценты, градиент опросов, карточки и вкладки Polls, Inbox, Friends, Profile. Поддерживается тёмная тема.

## Запуск

1. Откройте **эту папку `android`** в Android Studio как самостоятельный проект.
2. Установите Android SDK Platform 35 и Build Tools 35.0.0 через SDK Manager. Выберите JDK 17 для Gradle.
3. Дождитесь Gradle Sync и запустите конфигурацию `app` на эмуляторе или телефоне.
4. Запустите общий сервер из корня репозитория:

   ```sh
   python -X utf8 server/manage.py init
   python -X utf8 server/manage.py import-schools server/examples/schools.json
   python -X utf8 server/app.py
   ```

5. В приложении откройте **Server Settings**. На стандартном Android Emulator адрес уже задан: `http://10.0.2.2:8080`. Для телефона в одной сети задайте `http://IP-КОМПЬЮТЕРА:8080`, а сервер запустите с `GAS_HOST=0.0.0.0`.

В PowerShell переменная задаётся так: `$env:GAS_HOST = '0.0.0.0'`. Не добавляйте `/health` или `/v1` к адресу. Для внешнего сервера используйте HTTPS. **Release допускает только HTTPS**; Debug дополнительно разрешает HTTP для localhost, `.local` и частных IPv4. Перенаправления HTTP отключены. Чтобы изменить сервер после входа, сначала выйдите из аккаунта.

Используйте те же аккаунты и тот же сервер, что и на iOS. Новая регистрация требует школу из каталога, дату рождения с возрастом 14–19 лет и согласие с информацией о приватности. Сохраните одноразовый код восстановления. Для опросов нужны четыре подтверждённых друга.

## Функции

| Область | Реализовано |
| --- | --- |
| Аккаунт | Вход, регистрация, каталог школ с поиском, дата рождения, актуальная версия согласия |
| Восстановление | Восстановление по коду, смена пароля, замена recovery code, просмотр и отзыв сессий |
| Опросы | 12 вопросов в день, 4 варианта, голосование, баллы, пропуск, возврат пропущенных, смена вариантов |
| Inbox | Поиск, непрочитанные, загрузка старых страниц, отметка прочитанного, Report & Block |
| Друзья | Поиск внутри школы, заявки, принятие, отклонение, отмена, удаление, блокировка и разблокировка |
| Приглашения | Создание кода, системное меню отправки, принятие кода |
| Профиль | Изменение имени/логина, смена школы с паролем и подтверждением, история баллов |
| Модерация | Статус и ответ на жалобу, отмена конкретной анонимной блокировки, сброс всех анонимных блокировок |
| Данные | Экспорт JSON через системный выбор файла, удаление аккаунта с паролем и подтверждением |
| Офлайн | Зашифрованный профиль, друзья и первые 50 комплиментов, срок 7 дней, очистка при выходе |
| Обновление | Обновление вручную и каждые 30 секунд, пока приложение на переднем плане |
| Напоминание | Добровольное локальное уведомление около 20:00, разрешение Android 13+, восстановление после перезагрузки/смены часового пояса |

Токены и кэш шифруются AES-GCM с ключом в Android Keystore, хранятся в `noBackupFilesDir` и исключены из резервного копирования/переноса. Пароли и recovery codes не сохраняются в preferences или файлы. Напоминание не является push-уведомлением о комплименте; Android может задержать его в режиме экономии батареи. Для нового голосования требуется сеть. Если ответ на голос потерян, клиент перечитывает состояние сервера перед следующей попыткой.

## Сборка и проверки

Wrapper включён в проект. Если Android Studio не создала `local.properties`, добавьте `sdk.dir=/путь/к/Android/Sdk` или задайте `ANDROID_HOME`.

Windows:

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleRelease :app:testDebugUnitTest :app:lintDebug
```

macOS/Linux:

```sh
bash ./gradlew :app:assembleDebug :app:assembleRelease :app:testDebugUnitTest :app:lintDebug
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Release APK не подписан: настройте собственный ключ для распространения; ключи не входят в репозиторий. Debug использует application ID `app.gas.korea.debug`, Release — `app.gas.korea`.

Для тестов нужен Python 3.10+ с SQLite и scrypt. `LiveApiTest` автоматически поднимает реальный сервер из `../server` на свободном порту с временной базой, создаёт тестовые аккаунты и удаляет данные после завершения. При необходимости задайте `GAS_TEST_PYTHON` полным путём к Python. Остальные тесты проверяют политику адресов, сериализацию запросов/ответов, ошибки, кодирование поиска и запрет редиректов. GitHub Actions собирает обе конфигурации, запускает тесты и Lint и прикладывает Debug APK.

## Структура

- `app/src/main/java/app/gas/korea/data` — модели API, HTTP-клиент, адрес сервера, защищённое хранилище.
- `GasViewModel.kt` — состояние сессии, синхронизация и операции пользователя.
- `ui` — Compose-экраны и общие компоненты оформления.
- `notifications` — локальное ежедневное напоминание.
- `app/src/test` — JVM-проверки клиента и интеграция с Python API.
- `app/src/androidTest` — тест четырёх вкладок и Android Keystore с сохранением скриншотов на тестовом устройстве.

Версии сборки зафиксированы: [AGP 8.9.2 / Gradle 8.11.1](https://developer.android.com/build/releases/agp-8-9-0-release-notes), Kotlin и [Compose Compiler plugin](https://developer.android.com/develop/ui/compose/setup-compose-dependencies-and-compiler) 2.1.20, Compose BOM 2025.04.01.

Проверки устройства и ограничения документируются в [VALIDATION.md](VALIDATION.md). Общий контракт сервера — [../docs/API.md](../docs/API.md).
