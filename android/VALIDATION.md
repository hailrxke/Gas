# Проверка Android-клиента — 2026-10-08

Выполнено локально на Windows с JDK 17, Android SDK 35 и Gradle Wrapper 8.11.1:

- `:app:assembleDebug` — Debug APK собирается.
- `:app:assembleRelease` — Release APK собирается с R8, без ключа подписи для публикации.
- `:app:testDebugUnitTest` — **9 тестов, 0 ошибок**.
- `:app:lintDebug` — **0 ошибок**. Предупреждения касаются доступных новых версий зависимостей и предложений использовать Kotlin extensions.
- `:app:assembleDebugAndroidTest` — тестовый APK экранов и Android Keystore собирается.

`LiveApiTest` использует настоящий `ApiClient` Android-проекта, поднимает Python API с отдельной временной базой и проверяет: каталог, регистрацию пяти пользователей, приглашение, взаимную дружбу, поиск, пропуск/возврат опросов, голосование, защиту от повторного начисления баллов, анонимность Inbox, прочтение, жалобу/разблокировку, редактирование профиля, экспорт, отзыв сессии, смену пароля, восстановление, замену кода и удаление аккаунта.

Другие JVM-тесты проверяют Debug/Release-политику адресов, недопустимые URL, кодирование поиска с `+`, Unicode и `&`, Bearer-токен, PATCH, сохранение пробелов в паролях, булевы поля JSON, ошибки 401/409/428/429, запрет HTTP-редиректов и nullable/неизвестные поля ответов.

## Что ещё нужно проверить на устройстве

На этом компьютере не установлен драйвер аппаратного ускорения Android Emulator. Попытка запуска AVD API 35 с программной эмуляцией не дала доступного устройства в ADB. Поэтому **интерфейс, Android Keystore и уведомления в запущенном Android-приложении здесь не подтверждены**, скриншоты реального запуска не получены. Успешная сборка не заменяет эту проверку.

На подключённом тестовом телефоне или работающем эмуляторе:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

`ScreenSmokeTest` использует собственный HTTP fixture на устройстве, проверяет отображение четырёх вкладок и работу шифрованного хранилища (токен, изоляция серверов/сессий, истечение и очистка кэша). Тест не использует реальные аккаунты. Скриншоты сохраняются в каталоге приложения:

```sh
adb pull /sdcard/Android/data/app.gas.korea.debug/files/screenshots ./screenshots
```

Дополнительно пройдите следующие сценарии с общим сервером:

1. Регистрация, выбор школы, согласие, сохранение recovery code; вход существующим iOS-аккаунтом.
2. Пять пользователей одной школы, четыре принятых друга, голосование и получение комплимента на другом клиенте.
3. Длинные имена, маленький экран, крупный системный шрифт, клавиатура, поворот экрана и тёмная тема.
4. Inbox с поиском и более чем 50 записями; потеря сети во время голоса; смена дня по Корее.
5. Перезапуск без сети после синхронизации, выход офлайн, отсутствие кэша после выхода и при входе другим пользователем.
6. Смена школы с подтверждением, смена пароля, отзыв сессии, восстановление по коду, экспорт через системный выбор файла, удаление тестового аккаунта.
7. Жалоба и её статус, отмена блокировки и сброс анонимных блокировок.
8. Напоминание: разрешение/отказ Android 13+, доставка около 20:00, перезагрузка, смена часового пояса, отключение при выходе.

GitHub Actions настроен на сборки, JVM-тесты и Lint. Удалённый workflow в рамках этой работы не запускался. Публикация в Google Play и подпись Release не выполнялись.
