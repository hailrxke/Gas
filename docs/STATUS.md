# Состояние доработок

Обновлено 27 сентября 2026 года. «Реализовано» означает наличие кода и указанных автоматических проверок; это не подтверждение работы нового интерфейса на iPhone. Приложение остаётся технической альфой, английская локализация сохранена.

| Прежнее упрощение | Что изменено | Что ещё ограничено |
|---|---|---|
| Школа — произвольная строка | Постоянные ID, поиск каталога, JSON/CSV-импорт, загрузчик NEIS, миграция старых групп | Полный настоящий каталог нужно импортировать с собственным ключом или из проверенного файла; обучение не подтверждается |
| Возраст выбирался числом | Новые аккаунты указывают дату рождения, сервер вычисляет возраст по Корее | Дата заявлена пользователем; старым аккаунтам дата не выдумывается; подтверждения личности нет |
| Нет восстановления пароля | Одноразовый резервный код, смена пароля, замена кода, отзыв всех прежних сессий | Нет SMS/email; потеря и пароля, и кода не решается автоматически |
| Нельзя управлять устройствами | Список сессий, срок действия, выход из одной или всех остальных | Название показывает тип устройства, а не проверенный аппаратный идентификатор |
| Профиль нельзя изменить | Имя, логин, смена школы с паролем и подтверждением | Нет фотографий, редактирования даты рождения и проверки личности |
| Друзья только по точному логину | Поиск по части имени/логина, код приглашения на 7 дней, системное меню «Поделиться» | Нет импорта контактов, QR-сканера и universal links |
| 12 вопросов в коде | Внешний каталог из 48 английских вопросов, дневная ротация и снимки текста | Каталог редактирует оператор в JSON; веб-редактора и генерации контента нет |
| Выбор только из первых друзей | Учёт всех принятых друзей и частоты показов за 30 дней | Не заявляется доказанная статистическая беспристрастность при любых изменениях состава друзей |
| Перемешивание меняло лишь порядок | Серверная замена состава вариантов, до 3 раз на вопрос | При 4 друзьях заменить людей невозможно; при 5–7 часть вариантов повторяется |
| Пропуск не сохранялся | Пропуски и возврат вопросов сохраняются в базе | Нет офлайн-очереди голосов или пропусков |
| Голосование с одним другом | Требуются минимум 4 принятых друга | Это не гарантия анонимности; догадки и ложные аккаунты остаются возможными |
| Ограниченная история Inbox | Постраничная загрузка по 50, поиск, общий счётчик непрочитанных, фильтрация блокировок до пагинации | Нет realtime-соединения и APNs; историю очищает заданная политика хранения |
| Нет обновлений и уведомлений | Обновление данных раз в 30 секунд в активном приложении; добровольное местное напоминание в 20:00 | Уведомлений о новых комплиментах и фоновой синхронизации нет |
| Баллы — только счётчик | Транзакционный журнал начислений, история последних 100 и полный журнал в экспорте | Баллы ничего не покупают и не имеют денежной стоимости |
| Жалобы лишь записывались | Статус и ответ оператора, приостановка аккаунта, аудит, отмена анонимных блокировок | Ручная работа через CLI; нет команды модераторов, админ-панели и автоматических решений |
| Слабая защита повторных запросов | Ограничения по IP и логину, доверенные прокси, уникальность голосов, хеши сессий и кодов, request ID | Нет распределённой защиты, CAPTCHA, проверки устройства и независимого аудита безопасности |
| Любой сетевой сбой рушит состояние | Частичные обновления разделов, кэш профиля/друзей/50 комплиментов с защитой iOS, выход без сети | Нет автономной записи; кэш проверен по коду, поведение файловой защиты на iPhone ещё нужно испытать |
| Нет управления своими данными | Экспорт JSON, серверная версия согласия, удаление аккаунта с обезличиванием доставленной истории | Текст не заменяет юридическую политику; оператору нужны контакты и процедура обращений |
| Нет миграций/обслуживания | Схема v2, резервная копия до миграции, проверяемый backup, retention-команда, systemd-шаблоны | Сервис, таймер, HTTPS, внешний backup и мониторинг нужно установить на выбранном сервере |
| Нет метрик | Счётчики дневных событий и D1/D7 через CLI без стороннего SDK | Нет дашборда, crash reporting и данных реального пилота |
| Не подтверждена iOS-сборка | Проект обновлён, Swift проходит синтаксический разбор, CI настроен | Обязательны Xcode-сборка и проверки на настоящих iPhone |

## Что нужно перед закрытым пилотом

1. Собрать приложение в Xcode и пройти сценарии [VALIDATION.md](VALIDATION.md), включая потерю сети, восстановление доступа и смену школы.
2. Выбрать сервер/домен, импортировать нужные школы, настроить HTTPS, службу, таймер очистки и отдельную копию базы.
3. Назначить оператора и канал обращений, согласовать текст приватности и сроки хранения, испытать обработку жалобы и восстановление базы.
4. Собрать небольшую группу тестировщиков и проверить понятность интерфейса, условия анонимности, удержание и поведение на реальных данных.

Для публичной публикации также остаются оформление иконки/материалов магазина, работа с App Store Connect и подписью, продуктовые решения по фотографиям, уведомлениям и монетизации. Они не заменены заглушками, изображающими готовый сервис.
